# P-1: the loop test, every track P arm (2026-11-26)

Raw results. Method: [2-methodology.md](../energy-controller/2-methodology.md),
section 2.3; code `examples/loop_test.py` at commit 60aa1e0; raw JSONL on the
sandbox at `~/runs/p1_60aa1e0.jsonl`.

## Setup

- GameScaling-0.8B text head (`Qwen3_5ForCausalLM`), fp32, P40 (200 W cap,
  peak 44 °C), one seed (0). 885 s for all arms.
- Six prompts of 384 tokens, then 128 free-running tokens per arm:
  - `loop1..3`: 128 tokens of WikiText-2 test text, then a phrase repeated
    to fill 256 tokens;
  - `realA..C`: WikiText-2 test segments.
- Greedy decoding for every arm except P0b (Mirostat samples).
- Energy arms start from the 2c dose: MLP 0.03 + attention 0.01, decay
  divisor 40. Every controller starts at level 1 (that dose).
- Measured starting values (no tuning):
  - τ = 3.92 nats, the model's mean surprise on WikiText-2 *train* text
    (Mirostat: the same τ in bits, 5.66);
  - δ₀ = 2.013 nats per token, P0c's own mean effect KL.
- Controller settings: η = 1e-3 (P1's δ rule), dose ×/÷1.01 per token,
  effect measured every 4 tokens on a copy of the cache, surprise averaged
  over 16 tokens.
- Scoring, as in 2c's loop script:
  - **d3** = distinct-3 of the 128 written tokens (under 0.5 = still
    repeating);
  - **ppl** = the unmodified model's perplexity of what was written on the
    real prompts (low = repetitive, high = incoherent).

Reference (the true continuation of the real prompts, first 128 tokens): ppl
5.6 / 13.0 / 5.5, d3 0.857 / 0.921 / 0.905.

## What the numbers show (no verdict yet)

- **Mirostat (P0b) breaks no loop:** identical to no energy on all three. In
  a loop the model puts nearly all probability on one token, so truncating
  to the top k changes nothing; surprise stays near 0. On real text it gives
  the highest distinct-3 (0.97–0.98) at an original-model perplexity of
  10–22 (the true text: 5.5–13).
- **Every energy arm raises loop distinct-3** above 0.5 on all three loops,
  except P1 × D on loop2 (0.30). No energy stays at 0.03–0.17.
- **P1b** rose by ×1.01 on every one of the 128 tokens (end level 3.54 =
  1.01¹²⁷): the model's own greedy surprise never reached τ. Its real-text
  perplexities are the highest of the controller arms (19–51).
- **P1 vs P1a** differ only where P1's δ moved: δ rose from 2.01 to about
  2.35–2.40 in P1 (surprise stayed under τ, so "bored" throughout), and
  P1's levels ended higher on the real prompts.
- **Greedy surprise is far under real-text surprise** (about 0.25–1.6 vs
  3.92 nats), so with τ from real text every surprise-driven arm reads the
  model as bored for the whole run.
- **Cost:** energy is 6.5× slower per token (0.18 vs 0.028 s), from the
  per-token Python loop in the energy hooks; the effect meter adds 0.026 s
  per measurement.
- One seed, 128 tokens: differences between the controller arms on a single
  prompt are within what one seed can show.
